# murums PS4 Unfself UI 0.1.0

Desktop GUI based on [SocraticBliss' ps4_unfself](https://github.com/SocraticBliss/ps4_unfself). Convert unencrypted, uncompressed fake-signed PS4 SELF files to ELF.

Choose an installer for normal use. Portable packages need full extraction. Python and Qt are included; GitHub's **Source code** downloads do not contain the app.

- Drag-and-drop batches, progress, errors and cancellation; inputs and existing outputs stay unchanged.
- Dark UI, GitHub links and update checks. Download updates through your browser and install them manually.
- Native builds and package tests for all four targets. [SHA-256 checksums](https://github.com/murums04/ps4-unfself-ui/releases/download/v0.1.0/SHA256SUMS.txt) and corresponding source included.

Windows executables are unsigned. Mac apps use an ad-hoc signature without Apple notarization; macOS may require approval in Privacy & Security. Windows 10 remains untested. No retail decryption or PKG extraction.
