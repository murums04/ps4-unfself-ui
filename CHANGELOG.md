# Changelog

## 0.1.0

- Desktop UI: drag-and-drop, multiple files, output selection and per-file results.

- Platform preparation: macOS Apple Silicon/Intel app and DMG builds; Linux x64 portable and Debian builds. Native CI verification is pending.
