# Changelog

## 0.1.0

- Desktop UI: drag-and-drop, multiple files, output selection and per-file results.
- Appearance: matching Windows title bars and a clearer About dialog with author/upstream GitHub links.
- Updates: automatic GitHub release check and manual browser download, with no automatic installation.
- Conversion: indexed segments, input validation, cancellation and protected originals.
- Distribution: portable ZIP, per-user installer, source archive and checksums.
- Platform preparation: macOS Apple Silicon/Intel app and DMG builds; Linux x64 portable and Debian builds. Native CI verification is pending.
